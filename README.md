# Band Gap Prediction using Machine Learning (Explainable AI Approach)

## 📌 Overview

This project focuses on predicting the band gap of materials using machine learning models, with an emphasis on interpretability and scientific reasoning.

## 🎯 Objectives

* Predict band gap using machine learning
* Compare models (Linear Regression, Random Forest)
* Apply explainable AI techniques
* Link predictions to materials science understanding

## 🧪 Methods

* Data preprocessing
* Model training (cross-validation)
* Evaluation (MAE, MSE)
* Feature importance analysis

## 📊 Tools

* Python
* Pandas, NumPy, Scikit-learn
* Google Colab

## 🔍 Status

Work in progress — improving model and adding explainability.
